# 육각 전장 (hexwar)

육각 타일 영토전. 6개 출신 지역의 팀이 관문을 뚫고 중앙 10레벨 성지를 노린다. 한 판은 약 60분.
지금 버전은 **브라우저에서 혼자, 봇 다섯 팀과 끝까지 한 판을 할 수 있는** 프로토타입이다(기획서 개발 순서 1~3단계 + 5단계의 게임 규칙).

## 실행

```bash
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
npm run build          # apps/client/dist/index.html 한 파일로 빌드
npm test               # 단위 테스트 (맵 검사, 전투 결정성, 저장/복원, 명령 검증)
npm run sim -- 7 1     # 봇 6팀으로 60분 한 판을 몇 초 만에 돌려 결과 요약 (시드, 팀당 인원)
npm run map -- 7 map.svg   # 시드 7 맵을 SVG로 저장
```

## 웹에서 열기 (claude.ai 밖)

### 혼자 하기·시뮬레이션만
`npm run build` 로 만든 `apps/client/dist/index.html` 한 파일을 브라우저로 열면 된다(서버 필요 없음, 진행은 브라우저에 저장).

### 멀티플레이까지: 게임 서버 띄우기
`apps/server/server.mjs` 는 게임 페이지를 내주고 멀티플레이 방(로비·자리·명령·틱)을 중계하는 작은 Node 서버다.
판은 방장 브라우저가 돌리고 서버는 메시지만 나른다.

```bash
npm install
npm run serve          # 빌드 후 http://localhost:8080 (PORT 로 바꿀 수 있음)
```

- **같은 와이파이 친구와**: 친구는 `http://내컴퓨터IP:8080` 으로 접속
- **인터넷으로 잠깐 공개**: `npx localtunnel --port 8080` 이나 `ngrok http 8080` 이 주는 https 주소를 공유
- **계속 띄워 두기 (무료)**: 이 저장소를 GitHub에 올리고 [Render](https://render.com)에서 *New → Blueprint* 로 연결하면 `render.yaml` 대로 배포된다 (웹소켓 지원). 도커를 쓰는 곳(Fly.io, Railway 등)은 `Dockerfile` 을 쓰면 된다.
- 게임 페이지를 다른 곳(정적 호스팅, 파일)에서 열 때는 주소 끝에 `?server=wss://서버주소/ws` 를 붙이면 그 서버로 멀티플레이를 한다.

## 구조

```
packages/shared/src     ← 게임 규칙의 심장. 서버를 붙일 때도 그대로 쓴다
  balance.ts            기획서의 모든 숫자 (밸런스는 이 파일만 고친다)
  hex.ts                축 좌표, 이웃, 거리, 픽셀 변환
  rng.ts                시드 난수 (상태가 숫자 하나 → 저장·리플레이 가능)
  mapgen.ts             시드 → 지역·산맥 벽·관문·성지·지형·스폰, 연결성 검사
  pathfinding.ts        A* (적 시설은 "부수는 시간만큼 비싼 칸")
  generals.ts           장수·스킬 15종·무작위 모집(발탁)·NPC 수비군
  combat.ts             10라운드 전투 시뮬레이터
  game.ts               1초 틱 엔진: 이동, 점령, 공성, 경제, 건축, 시설, 승리 조건
  bot.ts                단순 봇 (짓고, 모으고, 이길 수 있는 인접 땅을 먹는다)
apps/client/src         ← 캔버스 지도 + 모바일 우선 UI (프레임워크 없이 TypeScript)
tools/sim/src           ← 헤드리스 한 판 시뮬레이터, 맵 미리보기
```

## 다음 단계 (멀티플레이)

`packages/shared`의 `Game`은 이미 서버에서 돌리기 좋게 되어 있다: 상태가 순수 JSON이고, 모든 행동이
`game.order(...)`, `game.build(...)` 같은 명령 함수를 거치며, 결과는 `step()`이 1초마다 계산한다.
서버는 Colyseus 방 하나에 `Game` 하나를 두고, 클라이언트 메시지를 명령 함수로 넘기고, 틱마다 바뀐 상태를 보내면 된다.

디버그: 브라우저 콘솔에서 `__hexwar.game`으로 현재 상태를 볼 수 있다.
